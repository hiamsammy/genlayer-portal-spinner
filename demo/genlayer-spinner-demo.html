GenLayer Spinner — v2, built from the real mark

Traced directly from the official symbol you shared. The mark stays fixed, full proportion, uncompromised — exactly as the brand guidelines specify. All the "loading" motion lives in a single thin ring in Kinetic Cobalt (#110FFF) that orbits around it.

The mark's fine detail (the inner notch, the small core triangle) only reads cleanly from ~32px up. Below that it anti-aliases into a blob, so below 32px it's better to drop the mark and keep just the ring — plain, universally read as "loading," still in brand color. Two tiers, one system.

Tier 1 — Hero (32px+): mark + orbit ring

Loading pages, full-panel loading states, empty states, splash moments — anywhere the spinner is the main thing on screen.
